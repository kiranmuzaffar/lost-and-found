# Lost and Found

## 📌 Project Overview

Lost and Found is a full-stack web application designed to help people report, search, and track missing persons and lost or found items through a centralized digital platform.

The system provides an organized way for users to submit reports with relevant details and images, search using filters, and interact through comments and sharing features.

Unlike traditional methods that rely on scattered social media posts and personal communication, this platform offers a structured solution for managing reports, verifying information, and improving the recovery process.

It supports both registered and unregistered users, while administrators are responsible for report verification, content moderation, case status management, and match alerts.

## ✨ Key Features

- **User Authentication:** Secure registration and login with encrypted passwords.
- **Lost and Found Reporting:** Submit reports for missing persons and lost or found items.
- **Advanced Search:** Search reports using filters.
- **Image Uploads:** Upload images with reports.
- **Comments and Sharing:** Interact with reports and share information.
- **Admin Dashboard:** Manage users, reports, and inappropriate content.
- **Report Verification:** Admin verification to help reduce fake reports.
- **Match Notifications:** Alerts when a match is confirmed between lost and found reports.
- **Password Recovery:** Reset passwords using email OTP.
- **Statistical Analysis:** Display monthly reports and statistics through charts.

## 🎯 Project Objectives

1. Allow users to report lost or found items.
2. Provide search results with filtering options.
3. Reduce fake reports by 70% through admin verification.
4. Send alert notifications after a match is confirmed.
5. Support at least 500 concurrent users without system delay.
6. Allow users to upload images with reports.
7. Display monthly statistics with 100% accurate data.
8. Provide secure login with encrypted passwords.
9. Enable password recovery through email OTP.
10. Maintain at least 95% system uptime.

## 🔄 System Workflow

1. Users access the platform and search for lost or found reports.
2. Registered users can create reports and interact with posts.
3. Report details and uploaded images are processed by the backend.
4. MongoDB stores the application data.
5. Administrators verify reports and manage inappropriate content.
6. The system supports matching lost and found reports.
7. Alerts are sent when a match is confirmed.
8. Monthly statistics help monitor reporting activity.

## 🎯 Project Purpose

The main goal of this project is to provide a reliable, user-friendly, and centralized platform that reduces information gaps, improves report management, and helps individuals and communities reconnect missing persons and lost items with their rightful owners.
